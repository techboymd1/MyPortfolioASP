# MyPortfolioASP

A personal portfolio website built with C# and ASP.NET Core Razor Pages.

About the Project
MyPortfolioASP is a portfolio web application created to showcase my development work and demonstrate my web development skills.
Technologies Used
C#
ASP.NET Core 9
Razor Pages
HTML5
CSS3
JavaScript
Bootstrap
Features
Portfolio website pages
Responsive styling
Admin area for managing portfolio projects
Cookie-based authentication
Project management services
Requirements
.NET 9 SDK
Visual Studio Code or Visual Studio
A web browser
How to Run Locally
Clone or download this repository.
Open the project folder in VS Code.
Open the terminal in the project folder.
Run: dotnet restore
Run: dotnet run
Open the localhost URL displayed in the terminal.
Project Status
This project is a work in progress. Improvements may be added as development continues.
